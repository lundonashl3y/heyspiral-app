# Design & User Experience

## Overview

The design process for HeySpiral focuses on creating an accessible, supportive, and user-centered mobile experience.

Design decisions are guided by user research, community insights, and the goal of creating a platform that feels intentional compared to traditional social media experiences.

---

# Design Goals

The primary goals for HeySpiral are:

- Create an approachable user experience.
- Make wellness tools easy to access.
- Encourage reflection and personal growth.
- Build a platform that feels supportive and engaging.
